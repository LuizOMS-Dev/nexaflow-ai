# NIA — Tools (MVP)

Somente leitura e navegação:

| Capacidade | Implementação |
|------------|---------------|
| Página atual | `resolveModuleFromPath` |
| Permissões | `permissionsForRole` |
| Entitlements | `getTenantLimits` |
| WhatsApp | `getTenantWhatsAppStatus` |
| Plano / agentes | snapshot estruturado |
| Navegação | action chips + allowlist |
| Tour | evento `nexaflow:start-platform-tour` |
| Suporte | mailto se configurado |

Sem tools de mutação.
